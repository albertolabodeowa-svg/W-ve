# WAVE 🌊

WAVE is an Instagram-style social media website built with:

- HTML
- CSS
- JavaScript
- LocalStorage

## Features

- Login
- Signup
- Logout
- Create posts
- Like posts
- User profiles
- Edit profile
- Explore
- Reels
- Messages
- Dark mode
- Responsive design
- LocalStorage
